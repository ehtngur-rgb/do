# 🤖 소리로 움직이는 도우미 로봇 친구 (손 없는 장애인 배리어프리 체험)

> **"손을 완전히 등 뒤로 하고, 오직 목소리만으로 컴퓨터와 로봇을 움직여보세요!"**  
> 손이 없는 지체장애인의 컴퓨터 사용 환경을 직접 체험하고, 음성인식 AI와 도우미 로봇 기술의 가치를 배우는 인터랙티브 3D 교육 프로그램입니다.

---

## 🌟 최신 업데이트 및 주요 기능

### 1. 🤖 전 과정 100% 일관된 로봇 목소리 & 자연스러운 자기소개 인사말
- **평범하고 친근한 자기소개 인사**:
  - 시작 시 "삐리비리" 같은 어색한 기계음 대신, 아이들의 눈높이에 맞춘 다정하고 명확한 자기소개로 변경되었습니다:
  - *"안녕하세요! 저는 여러분의 도우미 로봇 로보예요! 손을 쓰지 않고 목소리로 저에게 명령을 내려보세요!"*
- **전 과정 로봇 목소리 100% 유지 (끝까지 & 다음 학생까지)**:
  - 기존에 첫 인사 이후 윈도우 기본 목소리로 돌아가던 문제를 완벽하게 해결했습니다.
  - 6개 미션 수행, 물건 이동, 칭찬, 댄스, 조명 제어, 미션 완료, 그리고 **다음 학생 맞이하기까지 전 과정에서 단 1초도 기본 음성으로 돌아가지 않고 사랑스러운 꼬마 로봇 '로보' 목소리가 끝까지 그대로 유지**됩니다.
- **음성 겹침 방지 토큰 시스템**: 새로운 명령이나 말이 시작될 때 이전 음성 및 오디오를 0.01초 내로 완벽하게 중단(Flush)하여, 절대로 소리가 겹치지 않고 또렷하게 들립니다.

---

### 2. 🎯 총 6단계 무손(No-Hands) 퀘스트 미션 시스템
기존 4개에서 방 안의 다양한 물건들을 활용한 **6단계 미션**으로 대폭 확장되었습니다:

1. 🗣️ **로봇 깨우기**: `"로봇아!"` 하고 불러서 로봇 깨우기
2. 📦 **상자를 책상으로 옮기기**: `"상자를 책상으로 옮겨줘"` 말하기
3. 🧸 **인형을 상자에 올리기**: `"인형을 상자에 올려줘"` 말하기 *(상자 뚜껑 위에 안정적으로 올려줍니다)*
4. ⚽ **공을 침대로 옮기기**: `"공을 침대로 옮겨줘"` 말하기 *(바구니 속 장난감 공을 침대로 이동)*
5. 📚 **책을 선반으로 옮기기**: `"책을 선반으로 옮겨줘"` 말하기 *(책상 위의 책을 선반으로 정리)*
6. 💃 **신나게 춤추기 / 불 끄기**: `"신나게 춤춰줘"` 또는 `"불 꺼줘"` 말하기 *(축하 피날레)*

- 미션을 완료할 때마다 **아름다운 챠임 효과음**과 **색종이 꽃가루(Confetti)**가 터지며 황금별(⭐)이 체크됩니다.
- 6개 퀘스트를 모두 완수하면 승리의 팡파레와 함께 **황금별 6개(⭐⭐⭐⭐⭐⭐)**가 새겨진 **[🎖️ 배리어프리 AI 수료증]**이 발급됩니다!

---

### 3. 🧸 "인형을 상자에 올려줘" 자연스러운 동작 및 한국어 표현
- 닫힌 택배 상자 구조에 맞추어 기존의 *"넣어줘"* 대신 **"인형을 상자에 올려줘"**로 명령어가 직관적으로 변경되었습니다.
- 로봇의 안내 멘트 역시 상황에 맞게 자연스럽게 출력됩니다:
  - 명령 수신 시: *"네! 곰인형을 상자 위로 올릴게요!"*
  - 완료 시: *"곰인형을 상자 위에 올렸어요!"*
  *(※ 기존 습관대로 "인형을 상자에 넣어줘"라고 말해도 동일하게 인식되어 동작합니다.)*

---

### 4. 🔄 무중단 체험 종료 & 다음 학생 릴레이 로테이션
- 여러 학생이 차례대로 체험할 때 **브라우저 새로고침이나 마이크 권한 재요청 없이** 연속으로 진행할 수 있습니다.
- 6개 미션 완료 후 모달창에서 `[🔄 다음 학생 체험 시작하기]`를 누르거나, 마이크에 **"다음 학생"**, **"체험 종료"**, **"처음으로"**라고 말하면:
  - 3D 방의 모든 물건(상자, 인형, 공, 책), 조명, 로봇 위치가 제자리로 깔끔하게 초기화됩니다.
  - 마이크가 계속 켜져 있으므로 다음 친구가 바로 `"로봇아!"`라고 말하면 즉시 체험이 시작됩니다!

---

## 🚀 실행 방법 (원클릭)

1. 폴더 안의 **`실행하기.bat`** (또는 `run.bat`) 파일을 **더블클릭**합니다.
2. 마이크 권한 팝업이 뜨지 않는 전용 무손(Hands-Free) 브라우저가 자동 실행됩니다.
3. 화면 중앙의 **[🚀 체험 시작하기]**를 1회 클릭한 후, **마우스를 완전히 치우고 손을 등 뒤로 한 채** 편안하게 목소리로 명령해보세요!

## 🗣️ 대표 음성 명령어 모음

- **호출하기**: `"로봇아!"`, `"친구야!"`
- **상자 옮기기**: `"상자를 책상으로 옮겨줘"`, `"상자를 침대로 옮겨줘"`, `"상자를 바닥으로 옮겨줘"`
- **인형 올리기**: `"인형을 상자에 올려줘"`, `"곰인형을 침대로 옮겨줘"`, `"인형을 선반으로 옮겨줘"`
- **공 옮기기**: `"공을 침대로 옮겨줘"`, `"축구공을 책상으로 옮겨줘"`, `"공을 바구니에 넣어줘"`
- **책 옮기기**: `"책을 선반으로 옮겨줘"`, `"책을 책상으로 옮겨줘"`
- **조명 제어**: `"방 불 켜줘"`, `"방 불 꺼줘"`
- **신나는 댄스**: `"신나게 춤춰줘"`, `"고마워 잘했어!"`
- **방 정리하기**: `"방 깨끗이 정리해줘"`, `"모두 제자리로 정리해줘"`
- **체험 종료 & 다음 학생**: `"체험 종료"`, `"다음 학생"`, `"다음 친구"`, `"처음으로"`

## 📱 태블릿 / 모바일 연결 및 GitHub Pages 웹 배포

### 1. 같은 와이파이(Wi-Fi) 환경에서 연결하기 (가장 빠름)
1. 컴퓨터에서 `실행하기.bat`을 실행합니다.
2. 화면 오른쪽 위의 **[📱 태블릿 연결 (QR)]** 버튼을 누릅니다.
3. 화면에 나타난 **QR 코드**를 태블릿(아이패드, 갤럭시 탭)의 기본 카메라로 비추면 즉시 접속됩니다!

### 2. GitHub Pages로 인터넷 무료 웹 배포하기 (외부 어디서든 접속)
1. 저장소 `https://github.com/ehtngur-rgb/do`를 **Public(공개)**으로 설정합니다.
2. `깃허브_업로드.bat` 또는 `GitHub_Upload.bat`을 실행하여 모든 코드를 업로드합니다.
3. GitHub 저장소의 **[Settings] -> [Pages]**에서 Branch를 **`main`**으로 선택하고 저장합니다.
4. 배포 완료 후 **`https://ehtngur-rgb.github.io/do/`** 주소로 태블릿 및 패들렛에서 바로 접속할 수 있습니다!
